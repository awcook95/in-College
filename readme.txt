This repository contains a simple command line application called **InCollege**.
It simulates a networking site for college students and includes features such as:
- User account creation and login
- Job posting and searching
- Messaging between users
- Training modules

The project is implemented in Python. The main entry point is `incollege.py`.

## Running the application
Execute the application by running the following command from the repository root:
```
python incollege.py
```

## Running tests
Tests are written with `pytest`. To run them, execute:
```
pytest
```
